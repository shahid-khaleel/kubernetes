# Screenshots

Empty on purpose. This project was built in a terminal-only environment with
no browser/GUI available, so no screenshot could be captured honestly.

The main [README](../README.md) has `<!-- SCREENSHOT: ... -->` markers at
each point in the walkthrough where one would be useful — drop yours in
here (e.g. `01-jenkins-unlock.png`, `02-sonarqube-token.png`,
`03-pipeline-stages.png`, `04-app-browser.png`) and link them from those
markers as you run through the steps yourself.
